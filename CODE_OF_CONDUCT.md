# Code of Conduct

## Our pledge

Starlancer-OSS aims to be a welcoming space for anyone who wants to learn about, document, or improve
the game — regardless of experience level or background. We expect everyone taking part to act with
respect, patience, and good faith.

## Standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. Please read it at that link — it defines the expected behaviour, what is not
acceptable, and how enforcement works. By taking part (issues, pull requests, the wiki) you agree to
uphold it.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the project maintainer,
**[@LordBlacksun](https://github.com/LordBlacksun)** — via GitHub's private reporting on this
repository, or by contacting the maintainer directly. Reports are handled discreetly and in good
faith.

## Scope

This applies within all project spaces (the repository, issues, pull requests, and wiki) and when
representing the project in public spaces.
